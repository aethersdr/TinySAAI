# Getting Help with TinySAAI

TinySAAI is volunteer-maintained firmware within the AetherSDR project. There is
no SLA.

- **The official tinySA firmware and the instrument itself:** see
  [tinysa.org](https://tinysa.org/wiki/), the
  [tinySA forum](https://groups.io/g/tinysa) and
  [erikkaashoek/tinySA](https://github.com/erikkaashoek/tinySA). Please do not
  take TinySAAI problems there.
- **Bugs in TinySAAI:** file an issue with the bug-report template. Give the
  unit (model, hardware version), the `version` string, and the console
  transcript. Check whether the problem also occurs on the official firmware.
- **Proposals** that change what valid input does, a stored structure, a guard,
  the flashing path or the toolchain: open an RFC; see
  [GOVERNANCE.md](GOVERNANCE.md#rfc-process).
- **Security or safety issues:** do **not** open a public issue. See
  [SECURITY.md](SECURITY.md).
- **AetherSDR in general:** [AetherSDR Discussions](https://github.com/aethersdr/AetherSDR/discussions).
